`clinic_manager_release.jks` هو المفتاح اللي بيوقّع كل نسخة تنشرينها للعميل.

**خطر حقيقي:** لو ضاع هذا الملف، ما رح تقدري تنشري أي تحديث مستقبلي للتطبيق
بنفس التوقيع — العميل بيضطر يحذف التطبيق بالكامل (وبياناته المحلية غير
المرتبطة بحساب) ويثبّت نسخة جديدة من الصفر بدل تحديث عادي.
